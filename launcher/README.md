# 履析简历助手 macOS 启动器

真正的 APP 安装在 `~/Applications/履析简历助手.app`，桌面上的同名图标是它的快捷入口。双击桌面的 `履析简历助手.app` 后，启动器会：

1. 打开 Terminal。
2. 检查 `http://127.0.0.1:4173/` 是否是履析项目。
3. 未运行时执行 `npm start`；已经运行时显示运行状态。
4. 服务可访问后用默认浏览器打开网页。

服务运行期间请保留启动器打开的 Terminal 窗口。构建脚本会自动读取当前项目目录并写入 APP；项目文件夹移动后，只需重新运行构建命令。

重新构建：

```bash
zsh launcher/build-app.sh
```
